## What the product is
A free Bangla web app for HSC biology and medical admission students (Board & Beyond). The phone camera finds the student's head, hands and body and draws bones and organs on them (skull, brain, face muscles, eyes, hand bones, ribs, spine, neck, pelvis, arm/leg/foot bones, heart, lungs, windpipe, digestive organs, kidneys, bladder). Tap a dot for a Bangla card; there is a pointing quiz, a photo button, a no-camera 3D model view, and 52 generated reading pages.

## How to work
- Edit `content/*.json`, `tools/*`, `site/app.js`, `site/style.css`, `site/index.html`. Never hand-edit `site/read/*` or `site/data/*`; run `node tools/build.mjs` (it also stamps the version).
- Models: `python -I tools/build_body.py _work/bp3d site/assets` (BodyParts3D download in `_work/`, git-ignored).
- Local test: `python -m http.server 8765 --directory site`, then `http://localhost:8765/index.html#test=_test/portrait.jpg&debug` (test photos in `site/_test/`, git-ignored). The in-app browser pane is throttled in the background: allow 40-60 s for loading and retry screenshots.
- Publish: commit on `main`, `git push origin main`, then `git push origin "$(git subtree split --prefix site main)":refs/heads/gh-pages --force`. The live site updates in 1-2 minutes; check that `index.html` contains the new version tag.
- Git identity is set locally (abdullahprobal noreply). End commit messages with the co-author line for the model doing the work.
